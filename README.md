# 📊 Sales Dashboard in Power BI

## 📌 Overview
This project presents an interactive **Sales Dashboard** created using **Microsoft Power BI** to analyze and visualize sales performance across different categories, regions, and time periods.  

The dashboard transforms raw sales data into meaningful insights — enabling businesses to monitor key metrics, identify trends, and make data-driven decisions.  

---

## 🎯 Objective
To design a visually appealing and insightful dashboard that helps:
- Understand overall sales performance.  
- Compare sales by product category, region, and salesperson.  
- Identify revenue trends over time.  
- Highlight top-performing employees and products.  
- Support decision-making through interactive visuals and KPIs.  

---

## 🧰 Tools & Technologies Used
- **Microsoft Power BI** – for data modeling, visualization, and dashboard creation.  
- **Power Query** – for data cleaning and transformation.  
- **DAX (Data Analysis Expressions)** – for calculated columns and measures.  
- **Excel / CSV Dataset** – as the primary data source.  

---

## 📁 Dataset Description
The dataset includes sales transaction records with fields such as:
- `Date` – Date of sale  
- `Product` – Item sold  
- `Category` – Product category (e.g., Grocery, Beverages, etc.)  
- `Salesperson` – Employee responsible for the sale  
- `Units Sold` – Quantity sold  
- `Revenue` – Total sales amount  
- `Region` – Area or branch where sales occurred

---

## 🧮 Data Preparation Steps
1. **Data Loading:** Imported sales data from Excel/CSV into Power BI.  
2. **Data Cleaning:**  
   - Removed duplicates and handled missing values.  
   - Ensured correct data types for numeric and date fields.  
3. **Data Modeling:**  
   - Built relationships between tables (e.g., Sales ↔ Products ↔ Employees).  
   - Created calculated columns and measures using DAX (e.g., Total Revenue, Average Sales).

## 📊 Dashboard Components

### 1️⃣ **KPI Cards**
- Total Revenue  
- Total Quantity Sold  
- Average Revenue per Sale  

### 2️⃣ **Visuals**
- **Donut Chart:** Sales by Category  
- **Bar Chart:** Revenue by Salesperson  
- **Line Chart:** Monthly Sales Trend  
- **Map Visualization:** Sales Distribution by Region  
- **Tooltip Pages:** Additional insights when hovering over visuals  

### 3️⃣ **Filters / Slicers**
- Date Range  
- Product Category  
- Region  
- Salesperson
